# 🧪 SauceDemo - Suite de Pruebas QA Manual y Automatización

Proyecto completo de Control de Calidad (QA) enfocado en la evaluación funcional y visual de la aplicación web [SauceDemo E-Commerce](https://www.saucedemo.com). Este repositorio documenta las prácticas estándar de testing manual, reporte estructurado de fallos, diseño de pruebas BDD y la futura fase de automatización con Playwright.

## 🎯 Metodología de Testing

- **Pruebas Funcionales y Exploratorias:** Verificación exhaustiva de los flujos críticos de usuario (Autenticación, Inventario, Carrito y Pago).
- **Desarrollo Guiado por Comportamiento (BDD):** Casos de prueba redactados en formato `Dado-Cuando-Entonces` para facilitar la transición a la automatización.
- **Clasificación de Defectos:** Categorización basada en severidad (Crítica, Alta, Media, Baja) usando plantillas estándar de la industria.
